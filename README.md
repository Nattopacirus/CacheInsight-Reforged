# 🚀 CacheInsight-Reforged

แอปพลิเคชันจำลองการทำงานของ Cache Memory (Cache Simulator) เวอร์ชันพัฒนาใหม่ยกระดับสถาปัตยกรรมรองรับการประมวลผล 1,000,000 Addresses

## 🏗️ Tech Stack
- **Frontend**: Next.js (React), Tailwind CSS
- **Backend**: FastAPI (Python)
- **Database**: SQL Server
- **Task Management**: FastAPI BackgroundTasks + ProcessPoolExecutor
